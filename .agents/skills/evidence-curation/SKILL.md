# Evidence curation — MPDK v0.1

Read the existing HFC manifests, evidence ledger and source status documents first; they remain canonical.
For each scientific record preserve identifier, exact source, DOI/PMID where verified, year, endpoint, population, metric, coefficients/CI, restrictions, original source locator, reviewer and validation status.
Use explicit states: source located; numeric extracted; independent equation reproduction; clinical applicability reviewed; release approved. Never collapse these states into 'validated'.
Record discrepancies as unresolved with a blocking scope, not as guessed numerical corrections.
If primary paper unavailable, a reliable secondary source can substantiate attributed published values when policy explicitly allows; distinguish it in UI and bibliography and avoid claiming primary audit.
No private patient records, original proprietary full-text PDF uploads to a public GitHub repo, or copied source figures without permission.
Provide an audit trail for changed/retired/deprecated IDs and consequences for default selection.
