# P2.15 — Moiseenko HyTEC: fitted dose–response, UQ и недопустимость «интервалов из независимых CI»

**Дата:** 9 октября 2026. **Источник:** загруженный пользовательский `HyTEC_02_Moiseenko_2021_Dose-response_modeling_primer.pdf` (10 PDF страниц), supplement `HyTEC_02_Moiseenko_2021_Dose-response_modeling_primer_supplement.docx` (6 страниц), DOI **10.1016/j.ijrobp.2020.11.020**. **Проверено:** полный извлечённый текст обеих работ, оригинальные **PDF pp5–7, Fig.2, Fig.3, Fig.4** просмотрены по изображению. Остальные PDF figures и все изображения supplementary материала **не заявлены как полностью проверенные**.

## Из опубликованной модели: это методический пример, а не клиническое ограничение HFC

Объединённый пример по симптоматическому пневмониту **G≥2**, бинарный endpoint: **96 пациентов, 13 событий (13.54%)**, физическая MLD. Статья демонстрирует 2-параметрическую logistic fit:

- `MLD50=6.06Gy`, `gamma50=1.19`.
- **95% profile-likelihood parameter intervals**, Fig.2/Fig.3: `D50 5.05–9.04Gy`, `gamma50 0.73–1.77`.
- **95% bootstrap parameter intervals**, Fig.4 после **2000 patient-level resampling histories**: `D50 5.20–8.70Gy`, `gamma50 0.79–1.89`. **Это не те же CI и не confidence band для TCP/NTCP прогнозов**.
- Вычисление null likelihood из исходной доли responders: `MLL_fit=-31.41`, `LL_null=-38.07`, `deltaLL=6.66`, `2 deltaLL=13.32`, **P≈.0003** в сравнении с null, как напечатано в тексте статьи (PDF p6). Значимость демонстрационного тренда **не означает** клиническую валидацию внешней модели HFC и не доказывает, что 6.06Gy является применимым порогом риска для пациентов SBRT.
- Условный heuristic >10 событий на параметр в статье упомянут как desideratum для стабильности; здесь лишь 13/2 = 6.5 events/parameter. Поэтому ориентироваться на напечатанное количество цифр fit как на фактическую точность нельзя.

## Почему интервалы ошибок нельзя строить по четырём углам прямоугольника

**Fig.3** демонстрирует профили по `D50` и `gamma50`, полученные **максимизацией лог-правдоподобия по *другому* параметру при каждом значении первого**. Это не независимые marginal samples. **Fig.4** показывает «бананообразную» коррелированную область пар параметров из bootstrap-реплик (2000 joint `(D50,gamma50)` pairs).

**НЕ допускается** брать `D50_lower` с `gamma_upper` и наоборот или считать каждый угол произведения CI допустимой одновременной моделью. Полученные таким способом нижняя/верхняя доверительные границы NTCP/TCP будут невалидны.

Для точки на клинической дозе `d`, распространение uncertainty требует:
1. индивидуальных исходных наблюдений `(D_i, event_i)` или доступного набора bootstrap/joint likelihood replicates, привязанных к дозовой метрике и endpoint;
2. совместного повторного fitting `(D50_i,gamma50_i)`, не независимого варьирования CI;
3. прогнозов `P_i(d)` **для каждой** пары и процентильных 2.5/97.5% границ **при данном d** с учётом выбранного joint confidence method;
4. проверки `goodness-of-fit` vs null model, объёма данных и риска экстраполяции вне исходного дозового интервала;
5. учёта клинических переменных, контуров, времени, методики дозного расчёта, а не только статистики fitted scalar curve.

**Fig.2** показывает отдельную 68%- и 95%-полосу модельной вероятности, которую нельзя отождествлять с Fig.3 profile likelihood CI и даже с Fig.4 bootstrap CI для **параметра**. Эти три объекта представляют разные статистические величины.

В supplement Appendix E1 совпадение logistic/log-logistic/probit функций в `D50=6.06Gy` и при сходном normalized slope **не делает их одинаковыми по всем дозам**. При выборе другого семейства sigmoid на одной и той же выборке нужны **новый fit и joint CI**. Подмена источника посредством выбора эквивалентного `D50` и `gamma50` от другой кривой недопустима. Авторы подчёркивают, что **из MLD нельзя восстановить mean EQD2** без полной гетерогенной DVH и фракционного расписания.

## Проверка соответствия HFC и решение для P2/P4

- Source `Moiseenko 2021` используется **только как методология для научной проверки HyTEC моделей**, а не как clinical `MLD50=6.06Gy` или 13.5%-риск-порог.
- Сегодняшние 23 independently reproduced source point estimates **не получают автоматически bootstrap CI**: опубликованные parameter bounds, построенные не на исходных patient joint replicates, не позволяют честно реконструировать индивидуальные uncertainty bands.
- На этапе P4 или `OutcomeModel/NTCP expansion` **запретить алгоритм `P(D50_lower,gamma50_upper)` как якобы 95% confidence bounds**; при отсутствии сырых данных выводить `model fit point / CI unavailable`, а не выдуманный диапазон.
- [Методологический unit regression](../tests/hytecMoiseenkoUncertaintySemantics.test.ts) фиксирует значения источника, отличие profile и bootstrap **parameter** bounds, likelihood ratio и nonclinical status для MLD50 example. Не является patient-level refit.
