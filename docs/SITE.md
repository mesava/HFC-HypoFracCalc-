# Сайт HFC

HFC реализован как статический сайт на React + TypeScript + Vite.

## Разделы сайта

Верхнее меню намеренно сведено к пяти понятным разделам:

- **Главная** — краткое описание проекта и состояние модулей.
- **Как пользоваться?** — пошаговая инструкция, примеры HFC и семь опубликованных teaching/regression cases исходного Hypo-Calc.
- **Калькуляторы** — единая точка входа во все расчётные workflow:
  - Быстрый BED/EQD₂;
  - Сравнение режимов;
  - Подбор режима по целевому EQD₂;
  - Коррекция курса / ошибки отпуска дозы;
  - Интерактивный календарь;
  - Перерывы в лечении;
  - Повторное облучение.
- **Методология** — формулы, доказательная база и три справочных инструмента:
  - Клинические ограничения;
  - Клинические исходы HyTEC;
  - Проверка сохранённого audit JSON.
- **О сайте** — назначение проекта, статус и список литературы.

Такое разделение отличает собственно **калькуляторы** от справочных evidence/QA-инструментов.

## Внешний вид и мобильная версия

- базовый размер шрифта увеличен относительно RC;
- основной дизайн по умолчанию — более плоский и клинический, без декоративного градиента и тяжёлых теней;
- доступны варианты **Clinical / Journal / Compact**;
- доступна независимая светлая/тёмная тема;
- настройки внешнего вида сохраняются локально в браузере;
- мобильная версия тестируется на viewport 390×844 px;
- интерактивный календарь использует внутренний горизонтальный scroll на узком экране и не должен расширять документ.

## Языки

Основной язык сайта — русский.

В шапке доступно переключение **RU / EN**. Русская и английская версии должны быть полноценными самостоятельными текстами без смешивания языков в одной фразе, кроме общепринятых сокращений, формул, официальных названий и библиографии.

## Раздел «О сайте»

Список литературы на странице «О сайте» формируется непосредственно из:

```
src/data/evidence/v0.1/sources.ts
```

Это означает, что библиография сайта следует за версией доказательной базы. Если источник добавляется или удаляется из реестра, список на сайте меняется вместе с ним.

Для публикаций с DOI и PMID отображаются ссылки на DOI и PubMed.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm ci
npm run audit:security
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

CI выполняет security audit, typecheck, unit tests, production build и отдельный Playwright browser/visual QA job.

## GitHub Pages

`.github/workflows/deploy-pages.yml` собирает и публикует сайт.

Рабочая версия должна публиковаться из ветки `main`. В период разработки отдельная разрешённая ветка может временно использоваться для предварительного просмотра.

Vite использует относительный базовый путь `./`, поэтому собранный сайт работает в подпути репозитория GitHub Pages.

## Серверная часть

В версии v0.1 серверная часть отсутствует.

Все расчёты и обращения к доказательной базе выполняются локально в браузере. Само приложение HFC не отправляет идентификаторы пациента или клинические вводимые данные на сервер.

Если в будущем появятся работа с DICOM, учётные записи или серверное хранение данных, архитектура конфиденциальности и безопасности должна быть отдельно пересмотрена до реализации.


## Предпросмотр develop

Стабильный публичный сайт остаётся связан с веткой `main`:

https://mesava.github.io/HFC-HypoFracCalc-/

Для пользовательской приёмки следующей версии используется отдельный URL:

https://mesava.github.io/HFC-HypoFracCalc-/develop/

Workflow `.github/workflows/deploy-develop-preview.yml` запускается при изменении `develop` и собирает единый GitHub Pages artifact:

- корень сайта заново собирается **только из `main`**;
- каталог `/develop/` собирается **только из `develop`**;
- preview не заменяет код стабильной версии в корне;
- `develop/preview-build.json` фиксирует SHA обеих веток, вошедших в конкретное развёртывание.

Это позволяет проводить browser/manual acceptance до выпуска `develop → main`.
