# HFC P5 — Sahgal 2021: структура для Dmax, две модели Table 3 и повторное SBRT Table 4

**Дата:** 16 октября 2026 г.  
**Источник:** оригинальный пользовательский PDF `HyTEC_10_Sahgal_2021_Spinal_cord_tolerance(1).pdf`, 13 страниц. Sahgal A et al., *Spinal Cord Dose Tolerance to Stereotactic Body Radiation Therapy*. IJROBP 2021;110(1):124–136, DOI [10.1016/j.ijrobp.2019.09.038](https://doi.org/10.1016/j.ijrobp.2019.09.038). 
**Границы работы:** прямое чтение основного текста и визуальная проверка таблиц 3 и 4 (PDF стр. 8 и 11, журнальные стр. 131 и 134); независимая LQ-арифметика и внутренние регрессионные тесты. **Не clinical commissioning, не независимая модель NTCP радиационной миелопатии.**

## 1. Почему существовавший `valueRange` недостаточно информативен

В Table 3 для 1–5 фракций приведены **две разные колонки с разными анатомическими структурами**, а не клинический доверительный интервал одного параметра:

| Фракций | Sahgal 2013: Dmax *thecal sac* (Гр) | Katsoulakis–Gibbs: Dmax *true spinal cord* (Гр) | Статус второй колонки |
|---:|---:|---:|---|
| 1 | 12,4 | 14,0 | исходная однофракционная модель |
| 2 | 17,0 | 19,3 | **LQ-экстраполяция** из 14 Гр/1 фракция |
| 3 | 20,3 | 23,1 | **LQ-экстраполяция** |
| 4 | 23,0 | 26,2 | **LQ-экстраполяция** |
| 5 | 25,3 | 28,8 | **LQ-экстраполяция** |

**Источник:** Table 3, PDF стр. 8, сноска `*` и выделенные курсивом значения. Для Katsoulakis и Gibbs структура определялась по КТ-миелографии или МРТ как собственно спинной мозг. Для Sahgal `thecal sac` — дуральный мешок, используемый как суррогат и возможный запас на геометрическую неопределённость. **Они не взаимозаменяемы без специального протокола контурирования и верификации.**

Авторы называют интерпретацию риска радиационной миелопатии **приблизительно 1–5%** при этих модельных ориентирах. Это **не** независимая калибровка риска для каждого численного значения, **не 95% CI** и не универсальное планировочное ограничение. Авторы подчёркивают большую неопределённость при высоких дозах и небольшое число зарегистрированных событий.

Округлённый `valueRange` оставлен в прежних **пяти идентификаторах** только для совместимости с базой HFC. Теперь он сопровождается строго типизированным полем `doseRangeModelProvenance`: `low` → `sahgal-2013`, `thecal-sac`; `high` → `katsoulakis-gibbs`, `true-spinal-cord`; для 2–5 фракций верхнее значение отмечено как `lq-extrapolation-from-1fx`. В UI прежний вид «12,4–14,0 Гр» заменён двумя явно подписанными величинами и локализованными пояснениями.

**Важный пример первоисточника:** PDF стр. 4 (журнальная 127) упоминает средние `Dmax` приблизительно **12 Гр на spinal cord** и **14,5 Гр на spinal cord PRV** в одном сравнении. Пример показывает, как сильно значение максимума зависит от выбранного контура; это **не новый дозный лимит**.

## 2. Независимый пересчёт Table 3, α/β = 2 Гр

```
EQD2_2(D,n) = D · (D/n + 2)/(2 + 2)
Sahgal 12,4 Гр/1фр → EQD2_2 = 44,64 Гр.
Katsoulakis–Gibbs 14 Гр/1фр → EQD2_2 = 56,00 Гр.
```

Числа для 2–5 фракций укладываются в погрешность округления приблизительно **0,22 Гр EQD2** внутри каждой модельной колонки. Это подтверждает **математическую согласованность LQ-представления**, а не клиническую валидность пересчёта при крупных фракциях. Upper-KG `19,3/23,1/26,2/28,8` не рекомендуются авторами как независимо проверенные 2–5-fx clinical planning limits.

## 3. Reirradiation: Table 4 и четыре независимых фактора

Table 4, PDF стр. 11 (журнальная 134), **прямо указывает `thecal sac` как структуру-суррогат**. В статье перечислены факторы меньшего наблюдавшегося риска:

1. Кумулятивный `thecal sac Dmax EQD2_2 ≤70 Гр`.
2. Текущий SBRT `thecal sac Dmax EQD2_2 ≤25 Гр`.
3. Отношение `current EQD2_2 / cumulative EQD2_2 ≤0,5`.
4. Интервал после предыдущего облучения **≥5 месяцев**.

Они уже численно реализованы и сохранились **без изменений** в `reirradiationGuidanceSets`. Нельзя выводить восстановление спинного мозга в процентах только по интервалу лечения и нельзя автоматически сравнивать `true spinal cord` Dmax с этими `thecal sac` условиями.

### Table 4: публикационная таблица не является автоматическим результатом «пройдено»

В Table 4 авторы предлагают повторные физические дозы для некоторых суммарных режимов. В ранее выполненном P2-проверочном регистре `docs/HYTEC_P2_SAHGAL_TABLE4_EQD2_LEDGER_2026-10.csv` отмечено, что при **условной** подстановке назначения предыдущего курса как действительно измеренного `thecal sac Dmax` (что исходная таблица не подтверждает) 50 Гр/25фр + 14 Гр/3фр даёт:

```
Предыдущий EQD2_2 = 50 Гр
Текущий EQD2_2 = 14·(14/3+2)/4 = 23,3333 Гр
Условный cumulative EQD2_2 = 73,3333 Гр (>70 Гр)
```

Это не свидетельство однозначной ошибки оригинала: предыдущий `Rx` не обязан равняться реальному `thecal sac Dmax`, и сумма независимых максимумов не равна гарантированно пространственному максимуму. Однако когда **реальный предыдущий `thecal sac Dmax` именно 50 Гр/25фр**, арифметический `cumulative ≤70` не выполнен, и HFC должен показать это независимо от присутствия 14 Гр/3фр в Table 4. `N/A` из Table 4 не подразумевает ни нулевую дозу, ни разрешение/запрет.

**Программное решение:** не импортировать Table 4 как библиотеку «разрешённых доз» и не смешивать её с критериями другого контура. Не включать автоматическую поправку на восстановление ткани.

## 5. Последующие научные задачи

Проверить provenance предыдущего `thecal sac` Dmax и contour/registration для всех исходных планов, source model CI/at-risk denominators, неопределённость при высоких дозах, а также возможность независимого review со стороны второго медицинского физика. Введение patient-level RM risk calculator по данным одного обзора Sahgal без внешней валидации **необоснованно**.
