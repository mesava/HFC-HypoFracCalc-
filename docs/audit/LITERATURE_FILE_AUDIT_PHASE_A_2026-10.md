## 4. Новые содержательные проблемы, которые выявились только при чтении приложений и переписки

### P0: оговорка к liver metastases BED10 cutoff

Письмо **Klement et al.** (HyTEC 21) критикует выбор фиксированного α/β=10 Гр и применимость простого BED cutoff к клинически неоднородным метастазам. Ответ **Ohri et al.** (HyTEC 22) прямо признаёт, что разделение по 100 Гр **может быть не клинически универсальным** и dose-response TCP не имеет физического «скачка» на границе.

HFC уже правильно хранит результат как две `stratified-observation` группы, а не как непрерывный изолированный TCP. Однако к отображаемой модели желательно добавить **явную ссылку на дискуссию 21/22**, чтобы пользователь не принимал сравнительные 93%/65% за назначаемый порог.

**Решение:** научное предупреждение / provenance-link, без замены 93%, 65% или авто-подбора 100 Гр.

### P0: независимая первичная проверка NSCLC 2012

HyTEC Lee 2021 подтверждает общую регресс-модель и предсказания near-plateau 43/47/50 Гр. Но размер-зависимые примеры 2-year LC 93/90/83% и 99/98/96% в `OutcomeModel` исходят из **Ohri et al., 2012**, которой **нет среди этих 60 файлов**.

Не утверждать, что все шесть таких чисел проверены из загруженной первичной статьи. Нужна отдельная первичная source check именно Ohri 2012 или документированный ранее результат проверки с указанием таблицы/страницы.

### P1: supplements могут менять interpretation

Предварительно прочитанные приложения показывают, что:

- **Milano optic supplement:** мета-анализ учитывал пересечения когорт, разнородность дозовых метрик и случаи исключения отдельных исследований. Эти ограничения нельзя потерять при представлении NTCP.
- **Lee NSCLC supplement:** таблицы содержат первичные группы TCP с разными T1 fractions, Rx-to-isocenter dose correction, длительностью и годами наблюдения. Поэтому табличные «43/47/50» нельзя выдавать за простую рекомендацию для любого T1/T2 без дозовой метрики и условий.
- **Brand rectal supplement:** определения отдельных G1/G2 исходов основаны на комбинациях конкретных клинических шкал при условии отсутствия исходной токсичности. Слова «кровотечение G1+» без определения endpoint недостаточны для будущей patient-specific NTCP-модели.

Полная сверка всех приложений, особенно таблиц fitted parameters, остаётся отдельной задачей.

### P1: пять писем HyTEC 21–25 — содержательный контекст

Материалы Song/Brown/Carlson/Grimm содержат явный спор о косвенном клеточном повреждении, механизмах SBRT и применимости LQ при больших фракционных дозах.

**Не вводить** из этих писем универсальную correction factor к BED/EQD2. Сохранить как контекст при оценке ограничений модели и экстраполяции.

### P1: evidence cutoff / source catalogue version

Сейчас `evidenceManifest` имеет `datasetVersion=2026.10-v0.2`, `evidenceCutoffDate=2026-10-07`, `releaseStatus=draft`. Четыре HyTEC contextual source references добавлялись после cutoff. Требуется разделить:

1. *numeric evidence dataset* version и cutoff;
2. *bibliographic source catalogue* revision;
3. независимую clinical-validation completion.

Не повышать статус `draft` до `validated` из-за автоматических тестов или этого аудита.

## 5. Явные ограничения текущего этапа

- Бинарные SHA-256 всех 60 файлов не считались: текущие контейнерные операции возвращают системные ошибки. Размеры/названия доступны из метаданных загрузки; это не хэш-реестр.
- **Не выполнена** полная независимая проверка каждой quantitative таблицы всех 20 статей, 15 HyTEC supplements и иных приложений.
- Не выполнены отдельные математические пересчёты всех source-derived TCP/NTCP fits с исходными коэффициентами и неопределённостями. Часть точек проверена непосредственным сравнением текста/таблицы, но это не полный secondary implementation validation.
- 60 файлов позволяют начать аудит, но не подтверждают идентичность всего ранее предоставленного 357-МБ ZIP.
- Никаких изменений в клинические числа, исходы, уровни риска, формулы, правила выбора коэффициентов или сайт в данном PR **не производится**.

4. **Brand 2021/2023:** все 19 применяемых `alphaBeta.ts` оценок и 95% ДИ основных таблиц 3/2 уже совпали. Остались endpoint definition, исключения baseline toxicity, DMF, разбор fit significance, таблицы и calibration plots приложений.
5. **RCR dose fractionation 2024:** построчная проверка `Regimen Library`, статусы guideline vs prescription and timing.
6. **ESTRO–EORTC/Appelt:** reirradiation workflow applicability, cumulative dose framework, near-max and overlap metrics.
7. **Provenance completeness:** источник Ohri 2012, книга BCR 2025 и другие материалы, присутствующие в source registry, но отсутствующие в данном наборе из 60 файлов.

**Публикационный барьер:** коэффициенты/модели можно менять только после доступной пользователю проверочной записи `источник → страница → цитируемая величина → единицы/метрика → HFC code path → тест`. Текущий отчёт — исследовательский контроль, а не одобрение клинического применения.
