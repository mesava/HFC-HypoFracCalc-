## 2. Разница между тремя уровнями проверки

1. **File identity:** совпадение имён/размеров и исторического SHA-256 (только у 40 HyTEC). В этом P6.2 никаких *новых* SHA-256 original bytes не вычислено; `archive_internal_entry_verified_in_P6_2=false` у всех 69.
2. **Source numerical review:** P3/P5 проверяли конкретные таблицы/points/формулы, но статус P5 `full_primary_numeric_pdf_checked` для **86 записей** равен `not-certified-in-this-matrix`, у **17** — `false`; ни одно значение `true` этой колонкой не декларируется. Отсутствие `true` здесь означает отсутствие соответствующей сертификации *в этой матрице*, а не отмену прежних подблоков проверки.
3. **Clinical validation:** независимое refit, воспроизведение uncertainty, внешняя калибровка и local commissioning **не выполнены**. Все 103 записи в P5 имеют `clinical_release_approved=false`; статус dataset остается `draft`.

По HyTEC отдельный `HYTEC_40_SOURCE_TO_CODE_LEDGER_2026-10-15.csv` содержит `all_pages_figures_tables_verified=NO`, `full_fit_CI_reproduced=NO`, `clinical_commissioned=NO` **для всех 40 файлов**. Это не повод обнулять точечные воспроизведения, но и нельзя объявлять источник полностью проверенным.

## 3. Реальная карта оставшихся источников

27 из 61 source IDs первоначально не имели прямого файла: **23** связаны с численными данными HFC и **4** используются без самостоятельных numerical records (Samai/Berremdani 2026 review, Paradis ReCOG 2026, Robertson 1998 larynx и Bender 2012 CNS repair). Нет оснований добавлять из этих четырёх универсальные коэффициенты автоматически.

**30 записей без исходного файла распределяются по семействам:**

| Семейство | Количество |
|---|---:|
| α/β | **13** |
| T½ | **4** |
| Dprolif / OTT | **12** |
| OutcomeModel Ohri 2012 | **1** |

**Важно по BCR:** пять старых α/β численно приняты по `Basic Clinical Radiobiology` (2025), Table 10.1, как по достаточному **вторичному** источнику в отдельном решении P3.14. Четыре auto-eligible при точном endpoint-match; исходные журнальные PDF желательны, но **не являются обязательной предпосылкой по прежнему решению**. Статус оригинала и статус обоснованности вторичного источника не смешивать.

**Приоритеты на уровне 61 source IDs (научный triage, не шкала клинического риска):**
- `critical`: 2 источников;
- `high`: 34 источников;
- `medium`: 12 источников;
- `low`: 13 источников;

Критические источники Royce/Ohri сохраняют отдельный `P6.1` gate; не переписывать численную модель в рамках P6.2. Основная группа `high` — репопуляция (разнородные Gy physical/BED/EQD2/day, `Tk`), репарация (`T½`, three CHART original abstracts vs fulltexts), HyTEC point-level source-locator/contour/fit audit и численные записи без исходного файла. RCR/ESTRO/ReCOG и контекстные работы не получают `alpha/beta` просто по наличию ссылки.

## 4. Минимальный контролируемый следующий пакет P6.2b

**A. Original archive identity.** Получить авторизованный доступ к ZIP, записать ZIP SHA-256, manifest entries (имя/путь, размер, CRC, SHA-256), не выполнять небезопасное извлечение, сравнить с 69-файловым реестром; определить, совпадают ли два одноразмерных ZIP. Отдельные Library PDF доступны по названию, но их бинарная проверка сейчас не завершена. Не помечать #56 выполненным.

**B. Non-HyTEC 29.** При получении байтов вычислить SHA-256, сопоставить с 29 историческими именами/размерами, затем приоритетно читать первичные таблицы α/β, CHART T½, Dprolif/Tk и RCR guidance. Не считать 40 HyTEC hashes доказательством того, что весь архив 69 источников проверен.

**C. Endpoint/source tier.** Для каждого из 23 недоступных в первоначальном комплекте численных источников использовать уже готовые P3/P5 crosswalk и отличать `official-author-abstract`, `accepted BCR secondary`, `published fulltext`, `source-fit unresolved`; требовать precise page/figure/table, dose metric, CI/follow-up. Не снижать четыре ранее принятых BCR auto defaults без новых научных оснований.

**D. P6.3 linkage.** Вынести первичную детальную проверку 14 репопуляций и 6 repair time параметров в следующий пакет P6.3, не позволяя `K`, `Dprolif` и `BED/day` объединяться в одну неподтверждённую единицу.
