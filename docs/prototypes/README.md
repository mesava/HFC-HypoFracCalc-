# Прототип дизайна HFC: А + Б

**На согласование, не для публикации.** Макет находится только в ветке `design-hybrid-ab-prototype` и не подключён к основному сайту.

[Скачать HTML-прототип](https://raw.githubusercontent.com/mesava/HFC-HypoFracCalc-/design-hybrid-ab-prototype/docs/prototypes/hfc-hybrid-ab.html) (сохраните файл и откройте локально в браузере).

## Идея

- **А — Рабочая станция физика:** внутренняя навигация по калькуляторам слева; ввод/календарь в центре; результаты справа, видимые во время работы.
- **Б — Научный атлас:** спокойная молочная палитра, ясная крупная типографика, лёгкие разделители вместо множества градиентных карточек, ссылки и ограничения в контексте расчёта.

## Демонстрируется

1. Главная — редакционная иерархия, клиническое позиционирование, безопасная точка входа.
2. Быстрый BED/EQD₂ — основные поля, live LQ (только для демонстрации), сводка в правой колонке.
3. Интерактивный календарь — изменение дня 0/1 фракция с пересчётом иллюстративных BED/EQD₂.
4. Светлая / тёмная тема, узкий экран / мобильная перестройка.

## Не является

- Клинически валидированным расчётным движком.
- Проектом объединения исходных компонентов без ревью.
- Готовой версией дизайна, утверждённой для production.

Все числа **иллюстративные**, справочные поля и клинические предупреждения в реальной версии должны быть связаны с существующим HFC core и source registry.

## Что нужно утвердить

- приемлема ли комбинация рабочей компоновки А с типографикой Б;
- нужна ли фиксированная панель результатов или достаточно сворачиваемой;
- плотность полей/таблиц и размер типографики;
- светлая/тёмная палитра и мобильная иерархия.

После обратной связи — отдельный production UI PR с визуальными/мобильными регрессионными тестами, без изменения клинических формул.
