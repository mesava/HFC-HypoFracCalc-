## 2. Контроль доступности и безопасности

- Заголовки: программа проверяет **фактический `getComputedStyle().color` и `backgroundColor`**, требуя коэффициент контраста минимум **4,5:1** на выбранных заголовках Reirradiation/HyTEC/Methodology. Это сознательно более строгая проверка, чем минимальный порог 3:1 для крупного текста.
- Поверхности: у выбранных scientific cards в dark theme максимальная RGB-компонента фона должна быть меньше 115; это ограниченный тест именно на яркие поверхности, не универсальная проверка accessibility.
- Клиническая смысловая информация — источник, номер фракции, доза/объём, тип ограничения и предупреждение — **не меняется**. Изменён только CSS и e2e-тест.
- В новом тесте остаются проверки single Clinical (без Journal/Compact), отсутствие горизонтального переполнения и сохранение light/dark; глобальные 45 visual captures выполняются параллельно.
- Проверка **не доказывает WCAG AA для всех элементов сайта**: это выборочный release-regression gate. Формальное accessibility-аудирование потребуется отдельно.
