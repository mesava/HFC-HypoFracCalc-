## 1. Royce 2021 — подтверждённое внутреннее противоречие, ответ авторов недоступен

Публикация: Royce TJ et al., *Tumor Control Probability Modeling and Systematic Review of the Literature of Stereotactic Body Radiation Therapy for Prostate Cancer*. IJROBP 2021;110:227–236. [DOI 10.1016/j.ijrobp.2020.08.014](https://doi.org/10.1016/j.ijrobp.2020.08.014).

```text
D = EQD2(alpha/beta=1.5 Gy)
```

## 2. Wang 2021 — исправлена степень неопределённости вокруг перехода 4fx → 5fx

Источник: Wang K et al., *Prostate Stereotactic Body Radiation Therapy: An Overview of Toxicity and Dose Response*. IJROBP 2021;110:237–248. [DOI 10.1016/j.ijrobp.2020.09.054](https://doi.org/10.1016/j.ijrobp.2020.09.054).

**Непосредственно сверены оригинальные страницы PDF 6–9 (журнальные 242–245) и рисунок Figure 1B.** Из источника явно следует:

1. Раздел 6, PDF p6: в исследовании с 4 фракциями **физические дозы были приведены к эквивалентной физической дозе за 5 фракций** посредством LQ **α/β=3 Gy**. Остальные перечисленные дозы NTCP относятся к 5 физическим фракциям.
2. PDF p7, `Urethra dose and late grade ≥2 urinary toxicity`: Zhang et al., **78 пациентов, 38 Gy/4fx**, urethra `D1cc`, `D0.1cc` и `Dmax`, поздняя CTCAE GU grade≥2. Авторский текст прямо повторяет переход на 5фр эквивалент с α/β=3 Gy. Это **параметр конверсии в данной статистической модели**, не общая «α/β уретры» для HFC.
3. **Figure 1B, PDF p8**, содержит подпись **Four Fraction Urethra D1cc/D0.1cc/Dmax** по оси X; при этом в **Figure caption, PDF p9**, авторы пишут, что выполняли fitting данных с переводом в 5-фракционный эквивалент. Следовательно, **алгоритм пересчёта описан однозначно**, но **на какую именно дозовую шкалу нанесены графические x-координаты Figure 1B**, пока независимо не подтверждено. Не утверждать, что вся модель ошибочна только по подписи; не использовать слепо изображённые x-координаты для клинического расчёта.
4. Source-reported fitted Probit `TD50/m` для D1cc **48.6 Gy / 0.14**, D0.1cc **52.6 Gy / 0.18** и Dmax **53.5 Gy / 0.18** и 68% CI, AUC только **0.60, 0.62, 0.61** соответственно. Низкая предсказательная способность, широкие интервалы, смешанные source dose axes, а также нет индивидуального внешнего validation set — достаточные основания **не добавлять** их как валидированный `NTCP`.

### Проверка LQ-пересчёта при α/β=3 Гр

```text
BED3 = D4 * (1 + D4/(4*3))
Solve D5 * (1 + D5/(5*3)) = BED3:
D5 = (5/2) * [-3 + sqrt(9 + 12*BED3/5)]
```

| Исходная доза на метрику OAR в 4fx | Эталонный физический 5fx эквивалент |
|---|---:|
| 43 Gy / 4fx | **47.386246 Gy / 5fx** |
| 44 Gy / 4fx | **48.502232 Gy / 5fx** |
| 45 Gy / 4fx | **49.618298 Gy / 5fx** |

Контрольный `Vitest` сравнивает значения прямой LQ-BED формулы и независимого квадратичного решения, включая обратную проверку BED. **Это иллюстрации дозовых метрик исследования**, а не клинические дозные ограничения или предписания на мишень.

### Чего пока не вносим

- Не переносим 5fx-эквивалент `TD50/m` в общую непрерывную NTCP-модель и не используем `α/β=3` как дефолт для всей уретры.
- Не приравниваем `Figure 1B` к надёжным порогам NTCP; curve validation/axis reconciliation требует original per-patient dataset или письменного пояснения авторов.
- Не смешиваем suggested `V(Rx)` мочевого пузыря, уретральный `Dmax` и rectal `Dmax` с fitted данными или после предыдущей RT.

**В UI всех трёх клинических ориентиров Wang** уточняются исходные 4fx данные, авторская LQ-конверсия к 5fx и несовпадение осевой подписи Figure 1B. Numeric constraints `5–10 cc`, `38–42 Gy`, `35–38 Gy` не менялись.
