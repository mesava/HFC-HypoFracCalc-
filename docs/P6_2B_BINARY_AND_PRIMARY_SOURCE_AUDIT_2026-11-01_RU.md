Архив содержит **64 записи: 2 папки и 62 документа**, распакованный размер **55,674,386 байт**. Для всех 62 entries успешно выполнено полное чтение с CRC32: **ошибок 0**. Отдельно четыре PDF.

**Всего 66 документов: 49 PDF, 12 DOCX, 4 DOC, 1 XML.** У всех 66 вычислены SHA-256, **0 точных дубликатов**. 49/49 PDF успешно открыты PyMuPDF, 2,277 страниц суммарно (44 PDF имеют извлекаемый текст на всех страницах); 12 DOCX проходят внутренний ZIP CRC и XML parse; XML разбирается; 4 старых DOC проверены **только по OLE2-заголовку**, их таблицы не распарсены.

**HyTEC: все 40/40 повторно полученных файлов совпадают по SHA-256 с октябрьским историческим реестром.** Контроль всей канонической серии `filename|sha256\n` (4701 ASCII байт) дал одинаковый FNV-1a32 `1828ddc4` в повторном извлечении и GitHub-реестре. Полный SHA-256 **каждого файла** указан в новой 66-строчной таблице; совпадение байтов не означает валидации формул/fit/covariance.

**Сверка с 69 историческими filenames: 66/69 (95.65%)** после удаления формального суффикса `(1)` у четырех отдельно загруженных PDF; **лишних файлов 0**. Три отсутствуют:

2. `Linear-Quadratic-Model-in-the-Clinical-Practice-via-the-Web-Application.pdf`

Для пунктов 2 и 3 метаданные файлов видны в пользовательской Library, но разрешённая побайтовая материализация отклонена; пункт 1 в повторно загруженных материалах не найден. Это контекстные позиции: отсутствие не позволяет утверждать, что численные HFC коэффициенты неверны. Не путать 40 MB `liter.zip` с недоступным исходным 357 MB `HypoCalc.zip`.

## 12 targeted source anchors по первоисточникам

Все номера страниц — **1-based PDF file page**, не номера, напечатанные в статьях. См. [12-page-anchor реестр](P6_2B_12_SCIENTIFIC_PAGE_ANCHORS_2026-11-01.csv).

- **Joiner/Bentzen, BCR 2025, PDF стр. 123 (printed 108), Chapter 10.6 Eq.10.2 и Table 10.3:** `Dprolif` в **Gy_EQD2/day** для небольших изменений OTT около оригинального schedule, kick-off `Tk` и ограничения гиперэкстраполяции. Таблица 10.3 повторно подтверждена по **изображению страницы**, включая 0.64 [0.42,0.86] Hendry; 0.8 [0.5,1.1] Roberts; 0.52 [0.29,0.75] Hinata; 0.24 [0.03,0.44] Thames; 0.54 [0.13,0.95] lung pneumonitis. Численная копия вторичной таблицы **не** воспроизводит первичные fitting equations; Hinata `tBEDmax` по-прежнему source-incompatible и заблокирован.
- **RCR 2019, PDF стр. 18 и 28–29, Appendix B:** `K=0.9 Gy_BED10/day`, `Tdelay=28d`. Независимо посчитано `35×2×1.2−(46−28)×0.9=67.8 Gy_BED10`. Решение уравнения компенсации `72+5d(1+d/10)−(51−28)×0.9=67.8` даёт `d=2.61577310586 Gy` и `2.62 Gy` с округлением, **совпадая с авторской страницей 29**. Алгебраически `0.9 Gy_BED10/day / 1.2 = 0.75 Gy_EQD2_10/day` при α/β=10 и reference 2Gy; без source matching нельзя переносить эти единицы на HFC Treatment Gap.
- **Brand 2021, PDF стр. 2 и 8:** rectal CHHiP `bleeding G1+` α/β 1.6 Gy [0.9,2.5]. Не обобщать на другие rectal endpoints.
- **Brand 2022, PDF стр. 2 и 6:** GU CHHiP dysuria G1+ 2.0 [1.2,3.2], hematuria G1+ 0.9 [0.1,2.2], G2+ 0.6 [0.1,1.7] Gy. Лишь эти три endpoints получили статистически значимое улучшение LKB-EQD2 fit относительно LKB без EQD2.
- **Vogelius/Bentzen 2020, PDF стр. 1 и 3:** prostate tumour α/β=1.6 Gy, fixed-effects 95% CI 1.3–2.0, random effects 0.8–2.4, I²=70%. Полученный PDF прямо указывает, что он **перестроен из PMC XML 04.10.2026** и **не** является publisher-typeset original.
- **FAST-Forward 2026, 10-y, PDF стр. 1:** ипсилатеральный рецидив в 10 лет: 40/15 — 3.6% [2.7,4.9], 27/5 — 2.9% [2.1,4.0], 26/5 — 2.1% [1.5,3.1]. Это наблюдаемые исходы, **не** вычисленные α/β Appendix Table D5.
- **Joiner/van der Kogel:** английское 4-е изд. 2009 и русское издание 2014 — две версии одного фундаментального источника, **не** независимые модели.

## Что ещё открыто

- 2,277 страниц технически прочитаны на доступность, но **не все индивидуально научно проверены**; только 12 целевых anchors с подтверждёнными локаторами. Ни одно из них не эквивалентно independent patient-level model refit.
- Исходный P5 corpus: 61 source ID, 103 evidence records; исходными 69 файлами представлены 34/61 source IDs и 73/103 records. **27 source IDs / 30 records** без файла в первоначальном корпусе требуют самостоятельной provenance/source review.
- Двухступенчатая проверка оригинальной дозовой основы `Gy_BED/day` vs `Gy_EQD2/day` для 10 explicit-only Dprolif ещё не закрыта; действуют научные gate P6.3/3b.
- Не закрыты численные несоответствия Royce и Ohri (#59), и source-package completion [#56](https://github.com/mesava/HFC-HypoFracCalc-/issues/56).
- Source-specific RCR 2024 coverage, full-text figures/tables для 103 records, 4 DOC supplementary and independent clinical commissioning — следующие задачи.
