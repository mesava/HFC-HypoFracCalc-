# HFC — три альтернативы будущего дизайна (на согласование)

**Статус:** концепции, НЕ внедрены. CSS/UI-темы текущего сайта не меняются этой задачей, кроме небольших подсказок к показателям и недоступной карточки будущей технологии.

Цель: заменить впечатление «генерические карточки ИИ» на интерфейс, достойный программного обеспечения медицинской физики. Отличия ниже **архитектурные** — компоновка и способ работы, а не только палитра.

## А. «Рабочая станция физика» — приборно-клинический

**Вдохновение:** рабочие столы TPS/QA, клинические информационные системы, серьёзные профессиональные инструменты.

Планировка десктопа:

```
[ HFC ] [Главная] [Как пользоваться] [Калькуляторы ▾] [Методология] [О сайте]     [RU EN] [☾]

┌────────────────┬────────────────────────────────────┬──────────────────────┐
│ СЦЕНАРИИ       │ РАБОЧЕЕ ПОЛЕ                      │ РЕЗУЛЬТАТ           │
│ Быстрый EQD    │  Календарь / форма / схема         │ BED / EQD₂          │
│ Перерывы       │  параметры и контекст              │ предупреждения      │
│ Коррекция      │                                    │ клинический контекст│
│ ...            │                                    │ аудит               │
└────────────────┴────────────────────────────────────┴──────────────────────┘
```

- Навигация: короткая горизонтальная верхняя + фиксированная внутренняя левая панель выбранного калькулятора.
- Цвет: нейтральные бело-серые поверхности, тёмно-синий акцент и минимум статусов.
- Шрифт: без засечек 17–18 px, чёткие табличные цифры, моноширинные дозы/единицы.
- Вместо множества карточек — компактные секции с разделителями; графики, календарь и дозовые таблицы занимают основное пространство.
- На мобильном: верхняя навигация сворачивается, сценарии — в выдвижном меню, результаты — закрепляемый блок снизу.

**Преимущества:** эффективность при ежедневной работе, знакомая визуальная структура. **Риск:** может быть слишком утилитарным для вводной страницы.

## Б. «Научный атлас» — университетский / журнальный

**Вдохновение:** серьёзный научный журнал, руководства AAPM/ESTRO, методические издания.

Планировка десктопа:

```
HFC                                         ФОТОННАЯ ДЛТ            RU | EN
─────────────────────────────────────────────────────────────────────────
Главная       Как пользоваться?       Калькуляторы       Методология       О сайте

                 КАЛЬКУЛЯТОР EQD₂
            Краткая постановка клинической задачи

┌─────────────────────────────────────────────────────────────────────────┐
│ Ввод: n, d, endpoint, α/β     │ Результат: таблица + формулы            │
└─────────────────────────────────────────────────────────────────────────┘
Методика расчёта / Источники / Ограничения / Экспорт отчёта
─────────────────────────────────────────────────────────────────────────
```

- Много воздуха, почти никаких рамок, без карточек с тенями и градиентами.
- Заголовки с умеренными засечками, основной текст — аккуратный sans-serif 17–18 px.
- Цвет: графит, молочный белый, один приглушённый бордовый/сине-серый маркер.
- Основной результат оформляется табличной строкой, рядом формула; рядом с каждым числом — доступная ссылка на источник и объяснение.
- «Как пользоваться?» выглядит как научное руководство с примерами, а не лендинг.

**Преимущества:** высокая научная достоверность и читаемость. **Риск:** менее удобен для многопараметрических калькуляторов.

## В. «Дозиметрическая консоль» — аналитика / приборная панель

**Вдохновение:** QA-системы, метрологическое программное обеспечение, промышленная аналитика.

Планировка десктопа:

```
[Главная][Как пользоваться?][Калькуляторы][Методология][О сайте]       HFC / ⏺

┌──────────────────────┬──────────────────────────────────────────────┐
│ Параметры расчёта    │ Схема/календарь и сравнение                 │
│ n / d / α/β          │                                              │
│ Evidence / scenario  │ [ линия / таблица / визуальная шкала доз ]  │
├──────────────────────┼──────────────────────────────────────────────┤
│ Источники и заметки  │ BED    EQD₂    OTT    предупреждения        │
│                      │ [сравнить] [аудит] [экспорт]                │
└──────────────────────┴──────────────────────────────────────────────┘
```

- Управление слева, главный визуальный инструмент посередине, компактная статусная панель результатов снизу.
- Минимальный набор сеток/отступов (8 px), моноширинные численные поля, акцент на аналитической таблице.
- Цвет: холодный светлый стальной; тёмная тема — не инверсия, а полноценная приборная палитра.
- Состояния «ввод изменён», «предупреждение», «недостаточно данных» обозначаются текстом/значком, не яркими карточками.
- Mobile: единая колонка «ввод → схема → сводка» с якорными вкладками.

**Преимущества:** максимальная плотность полезной информации, подходит для сложных QA-сценариев. **Риск:** перегрузка для нового пользователя.

## Общие обязательные требования

- 5 разделов верхнего меню и «О сайте» последним;
- одна чёткая иерархия типографики (основной текст не ниже 16–17 px);
- профессиональная тёмная тема;
- полнофункциональная мобильная версия и проверка горизонтального переполнения;
- подсказки с наведением, фокусом клавиатуры и касанием;
- клинические оговорки, происхождение чисел, units, endpoint и audit остаются видны;
- никаких анимаций ради анимаций и декоративных градиентов;
- строго не изменять клиническое ядро при дизайне.

## Решение

**Пока не выбирать и не внедрять.** После предпочтения пользователя можно подготовить три реальных high-fidelity макета *одной и той же страницы* (например, интерактивный календарь) и только затем менять UI, отдельно проверяя визуальные различия и регрессии.
