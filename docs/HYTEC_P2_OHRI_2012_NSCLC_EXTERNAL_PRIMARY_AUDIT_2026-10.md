## 2. Опубликованная функция

Авторы обучали логистическую регрессионную модель по **504 NSCLC опухолям от 482 пациентов**, получив **26 локальных рецидивов** при **среднем follow-up 18,4 месяца** (исходный факт, не медиана). Pooled 2-year LC учитывает назначенную **PTV prescription dose**, а не Dmax PTV, дозу в изоцентре или эквивалентную точку GTV.

`BED10 = D*(1 + D/(n*10))`, где D суммарная назначенная доза в Gy, n число фракций.

`sBED = BED10 - c*L`, где L — **максимальный диаметр опухоли, см**, `c = 10 Gy/cm`.

`TCP_2y = exp((sBED - TCD50)/k) / [1 + exp((sBED-TCD50)/k)]`.

Результаты публикационного fit: `TCD50=0 Gy`, `k=31 Gy`. Эквивалентное устойчивое вычисление `TCP_2y=1/[1+exp(-sBED/31)]`. Ни один из параметров, `α/β=10` либо `L` не разрешено заменять значением для HCC/brain/LQ-late-tissue.

Проверка авторских промежуточных sBED thresholds из Abstract:
- `sBED=44 Gy` → `TCP=80,54%` (печатное ≈80%);
- `sBED=69 Gy` → `TCP=90,25%` (≈90%);
- `sBED=93 Gy` → `TCP=95,26%` (≈95%).

## 4. Границы модели

Исходный текст **Discussion** явно описывает:
- **Только 10/504 (≈2%)** исходных опухолей лечились **за одну фракцию**; авторы предостерегают от использования модели для 1fx.
- **Фракционная доза ниже 8 Гр** и **длительность курса более двух недель** также выходят за область надёжной применимости.
- **TCD50=0 Gy не означает 50%-й контроль при отсутствии ЛТ**: подавляющее большинство наблюдений имеют `sBED≥50 Gy`, и исходная S-кривая для нулевого sBED не имеет клинической валидности.
- Исходная выборка многоцентровая, техники, PTV prescription и клиническое определение местного рецидива неоднородны; 26 events мало для точных parameter uncertainty bands.
- Исходный срок **2 года**, а не 1, 3 или 5 лет; поздние рецидивы и конкурирующие события (дистантный/узловой прогресс, смерть) модель не учитывала. В источнике подчёркнута потребность во внешней валидации.
