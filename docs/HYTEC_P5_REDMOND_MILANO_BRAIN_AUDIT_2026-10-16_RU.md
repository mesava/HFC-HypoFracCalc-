## 2. Redmond — четыре точки **1-летнего локального контроля отдельного очага**, не персональный TCP

**Исходная публикация:** PDF стр. 3 («Endpoints»); 7 («Data extraction» и «Factors Affecting Outcomes»); 9–12 (модели, Table 2, Table 3); приложение EA4 стр. 8–9. Включены 56 исследований с примерно **13 929 метастазами**. Контроль оценивался **на уровне очага**; OS в статье оценивали **на уровне пациента**. Источниковые результаты чувствительны к выбору определения рецидива, отличию радионекроза от прогрессирования, цензурированию смерти и доле пациентов с предшествующей или сопутствующей WBRT.

### 2.1 Модельная дозовая основа

- Численная доза — **prescription at the target/PTV margin**, не изоцентр, средняя/максимальная доза в GTV или D95 TPS без эквивалентной дефиниции.
- Для сводного анализа 1–5 фракций авторы использовали **single-fraction equivalent dose** на основе LQ с предположением **α/β = 20 Гр**; в графиках обозначено **SFED₂₀**. Значение не выведено надёжно для малых опухолей: около 99% анализируемых источников для них были однофракционными. Для средней/крупной группы сравнение фракций приводило к модельным α/β порядка 20 Гр и выше. **Это не универсальный α/β «для всех метастазов мозга» и не коэффициент для normal-brain toxicity.**
- Эквивалентная однофракционная доза вычисляется из `BED20(D,n)`:
```
BED20(D,n) = D × (1 + D/(20n))
SFED20(D,n) = [-20 + sqrt(20² + 4×20×BED20(D,n))]/2
```

| Исходный режим | Независимый SFED₂₀ | Таблица 2 Redmond |
|---|---:|---:|
| 20 Гр / 1 фр. | 20,0000 Гр | 20 Гр |
| 30 Гр / 3 фр. | 21,6228 Гр | 21,6 Гр |
| 35 Гр / 5 фр. | 22,3265 Гр | 22,3 Гр |

Для сравнения те же режимы по source Table 2 при **α/β=2** дали бы SFED **20; 18; 16,8 Гр**. Биологические dose bases нельзя смешивать: α/β=2 в этой таблице используется для **CNS critical structure**, а α/β=20 — только для опухолевой кривой LC.

### 2.2 Параметры EA4 и четыре уже сохранённые точки

Логистическая функция исходной модели:
```
P(LC) = 1/[1 + (TD50/SFED20)^(4γ50)]
```

| Группа | EA4 для 1-летнего LC, 1–5 фракций | n исходных опухолей | Точка HFC | Воспроизведение модели |
|---|---|---:|---|---:|
| ≤20 мм | TD50 11,21 Гр, γ50 0,9749 | 10 106 | 18 Гр/1 → >85% | 86,374% |
| ≤20 мм | те же | 10 106 | 24 Гр/1 → ≈95% | 95,113% |
| 21–30 мм | TD50 12,44 Гр, γ50 0,7617 | 647 | 18 Гр/1 → ≈75% | 75,504% |
| 31–40 мм | TD50 9,15 Гр, γ50 0,4089 | 1 028 | 15 Гр/1 → ≈69% | 69,178% |

**Погрешности округления:** HFC хранит source narrative approximate percentages, не избыточную точность модели. Например, «>85%» в абстракте не заменено на 86,374%. **Временная точка важна:** при 18 Гр и малом очаге отдельная 2-летняя EA4 модель (TD50 13,88, γ50 1,3542) предсказывает **≈80,344%**, а модель 1-летнего исхода — **≈86,374%**. Они не взаимозаменяемы. Table 3 также содержит смоделированные 2-летние LC при клинических режимах, но не должна добавляться как дублирующий набор 1-летних точек.

**Источник неопределённости:** переменная опухолевая гистология, GTV→PTV 0–3 мм, технические варианты GK/LINAC, отличающиеся изодозы назначения и неодинаковая доступность предыдущей WBRT. Из EA4 95% CI отдельных TD50/γ50 **нельзя** построить корректный 95% prediction band без полного fit и ковариаций.

## 3. Milano — одна запись Vx не означает один и тот же контур во всех исходных исследованиях

Основной PDF стр. 4–5, 9–12; supplemental DOCX Figures E1–E4. Целевой clinical endpoint может быть: **любой некроз/отёк**, **симптоматический некроз** либо **некроз с хирургическим подтверждением/резекцией**. Авторы используют `tissue V12` — весь объём ткани при пороге 12 Гр **включая мишень** — как унифицированную ось. Но часть исходных публикаций давала только `brain V12` после исключения GTV. Для сопоставления авторы приближённо **прибавляли оценку медианного GTV** к brain V12. Эта сумма — study-level reconstruction, **не** «измеренный для каждого пациента» target-inclusive V12.

**Геометрический пример из PDF стр. 4:** для сферической мишени диаметром 2,5 см показаны `tissue V12≈15,6 см³` против `brain V12≈7,4 см³`. Это существенно разные числовые показатели даже до биологического моделирования. Оба обозначения не должны смешиваться с `Brain−PTV` или `Brain−GTV` пациентских DVH.

### 3.1 Существующие 7 исходных точек — сохранены

| Endpoint | Доза/объём | Сообщённая связь |
|---|---|---|
| Симптоматический RN, 1fx | tissue V12≈5/10/>15 см³ | около 10/15/20% |
| Любой RN/отёк, 3fx | brain + target V20 <20 см³ | <10% |
| Требующий резекции RN, 3fx | brain + target V20 <20 см³ | <4% |
| Любой RN/отёк, 5fx | brain + target V24 <20 см³ | <10% |
| Требующий резекции RN, 5fx | brain + target V24 <20 см³ | <4% |

**Новое типизированное поле:** у трёх однофракционных V12 добавлен `volumeBasisDerivation: "mixed-reported-and-estimated"`. Оно документирует источник унификации объёма. Четыре фракционированных V20/V24 остаются с уже существующим `volumeBasis: "target-inclusive-tissue"`; не утверждается, что их объёмы были индивидуально восстановлены тем же способом.

### 3.2 Table 3 — численно разные источниковые кривые, не смешивать с семью точками абстракта

**Первичный PDF стр. 12 Table 3, Fig. 5–6:** результаты опубликованных моделей *любого* RN/отёка демонстрируют выраженную неоднородность.

| Объём V12 | Chin/Inoue/Peng, grade 1–3 | Korytko, grade 1–3 |
|---:|---:|---:|
| 5 см³ | 3,6% | 19,6% |
| 10 см³ | 4,8% | 25,8% |
| 20 см³ | 8,6% | 41,5% |

Разница не объясняется только округлением: исходные выборки и методы учёта исхода отличаются. Table 3 **не является** единым источником 10% симптоматического RN при V12=5 см³, и недопустимо подменять им три исходные точки симптоматического RN. Отдельные Table 3 значения для `V14` составляют **4,1/6,0/12,1%** grade 1–3 и **0,4/0,8/3,4%** grade 3 с резекцией, соответственно при 5/10/20 см³.

В Таблице 3 также приведено преобразование порогов физических доз для фракционированного SRS при **α/β=2 Гр** как модельном допущении:
```
1fx V12 ⇔ 3fx V19,6 ⇔ 5fx V24,4
1fx V14 ⇔ 3fx V23,1 ⇔ 5fx V28,8
```
Это **равенство BED2 для физических порогов дозы**, а не эквивалентность анатомических контуров, клинических исходов или валидированных NTCP кривых.

**Другой важный источник uncertainty:** в Figure 1–4 использовалась логарифмическая функция от объёма, а в Figures 5–6 — обычная logistic по объёму. Дополнительный Figure E4 показывает модельную чувствительность к такому выбору. Без полного исходного набора, joint likelihood и covariance нельзя заявлять точность кривых/CI для индивидуального пациента.

## 5. Незакрытые вопросы для научного следующего шага

1. Получить per-cohort/individual measurements для проверки целого исходного likelihood: **отчёт EA4 сам по себе этого не обеспечивает**.
2. Верифицировать со специалистом, как в каждом опубликованном случае определялась дозовая основа: GK prescription margin vs LINAC isodose/PTV prescription и предшествующая WBRT.
3. В Milano сопоставить отдельно контуры интактных метастазов, послеоперационных лож и структур около мозга/ликворных пространств; исключить непроверенное перенесение fitted Vx-risk на reirradiation / brainstem.
4. Разделить source **parameter CI**, model confidence band и uncertainty transfer across populations; полноценные covariance и bootstrap недоступны в опубликованной сводке.
5. Повторно провести independent second-physicist review перед клиническим применением.

**Итог:** точные численные строки опубликованных моделей не заменены, но риск «скрытой подмены» PTV margin/SFED20 и reconstructed tissue V12 адресован на уровне структурированных данных, интерфейса и регрессионных тестов. Доказательная база HFC остаётся `draft`.
