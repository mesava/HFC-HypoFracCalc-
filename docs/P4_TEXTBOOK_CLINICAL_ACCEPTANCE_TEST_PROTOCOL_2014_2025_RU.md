- **Независимость:** медицинский физик должен вручную или в другом программном пакете пересчитать эталон **до** просмотра чисел HFC; подготовленные значения книги используются только для сверки. Врач оценивает трактовку, endpoint, популяцию, ограничения и корректность предупреждений, а не только совпадение EQD₂.

## A. Медицинский физик: ввод и численная проверка в интерфейсе

### Ф-01. BCR 2025, пример 10.1, стр. 106 (PDF 121): 1×8 Гр, спинной мозг

1. Нажать **Калькуляторы → Быстрый BED / EQD₂**.
2. Поле **Клинический исход**: `Миелопатия (спинной мозг)` / `spinal-cord-radiation-myelopathy` (название может немного различаться). Это обеспечивает релевантный endpoint; параметр далее задаётся **вручную**.
3. Выбрать вкладку **Своё значение** и ввести `Пользовательское α/β, Гр = 2`. Не выбирать автоматически опубликованный источник с другим α/β.
4. `Число фракций, n = 1`; `Доза / фракцию, Гр = 8`.
5. Ожидается **BED 40,00 Гр**, **EQD₂ 20,00 Гр**. Из книги: **20 Гр**. Формулы `BED=n d (1+d/(α/β))`, `EQD₂=BED/(1+2/(α/β))`.
6. Скачать audit JSON и проверить `selectionMode=manual`, `alphaBetaGy=2`, `eqd2Gy=20`. **PASS** если EQD₂ отличается не более `0,01 Гр`, BED `0,01 Гр`, вручную заданный α/β не выдан за измеренную тканевую константу.

### Ф-02. Русский учебник 2014, пример 1, стр. 209 (PDF 209): 4×5 Гр

Повторить **Калькуляторы → Быстрый BED / EQD₂**; endpoint — спинной мозг/миелопатия; **Своё значение α/β=2**; **n=4**, **d=5**. Ожидается **D=20 Гр, BED 70,00 Гр, EQD₂ 35,00 Гр**, эталон книги **35 Гр**. **PASS ±0,01 Гр**. Это LQ-дозовая сопоставимость, **не ограничение максимальной дозы на спинной мозг конкретного пациента**.

### Ф-03. BCR 2025, пример 10.2, стр. 106–107 (PDF 121–122): RAPID BID

**Проверка уровня расчётного ядра, НЕ отдельная полная экранная форма «BID EQD₂» в Quick EQD.** В `tests/p4Textbook2014And2025IndependentAcceptance.test.ts` проверяются: `n=10`, `d=3,85`, `D=38,5`, `α/β=3,4`, `m=2 в сутки`, `Δt=6ч`, `T½=4,4ч`; `H₂=exp(-ln2·6/4,4)≈0,389`, `EQD₂≈62,36 Гр`. В книге: **62,4 Гр** с округлённым H₂=0,39, полная репарация **51,7 Гр**, дополнительный эффект **10,7 Гр**. **PASS для 62,4 ±0,06 Гр, 51,7 ±0,06 Гр.** Отдельная Guttenberger модель в книге даёт **64,9 Гр**, и это **НЕ** ожидаемый результат Thames H₂ из HFC. Физик обязан отметить неполную ночную репарацию как отдельный источник неопределённости.

### Ф-04. Русский учебник 2014, пример 2, стр. 210 (PDF 210): 50 Гр + последние 20 Гр в BID

**Контроль ядра и решения об интервале, НЕ обычного Quick EQD UI.** 50 Гр уже облучены с 2 Гр/фр. Остальные `10×2 Гр` по `2 фр./сут`; `α/β=1,7`, `T½=4,4ч`. Для интервала **6ч — 74,2 Гр**, **8ч — 73,0 Гр** по книге (использованы табличные `H₂=0,39 / 0,28`). Точная экспоненциальная HFC: **74,201 Гр / 73,066 Гр**. **PASS ±0,11 Гр**; разница обусловлена округлением H₂ в книге. При меньшем интервале модель даёт более высокий поздний эффект; нельзя объявить вариант 6ч равноценным 8ч.

### Ф-05. BCR 2025, пример 10.4, стр. 108–109 (PDF 123–124): 40 vs 47 дней

**Калькуляторы → Перерывы в лечении**, выбрать клинический исход HNSCC/контроль опухоли головы и шеи. Установить:
- режим **Длительность вручную** (не календарь); `Число фракций=35`; `Доза/фракцию=2 Гр`;
- `Плановая длительность=40 дней`, `Уже проведено=20 фракций`, `Перерыв=7 дней`; эти значения — **техническая иллюстрация** разницы OTT 40→47, а не фактическая схема ACC;
- **α/β → Своё значение=10 Гр** (для сравнения временной разницы α/β при одинаковом физическом режиме сокращается);
- **Dprolif → свои Dprolif/Tk:** `Dprolif=0,7 Гр EQD₂/сут`, `Tk=21 день` **ручная учебная величина из примера 10.4**, не автоматический рекомендованный параметр HFC.
- Проверить поле изменения эффективной EQD₂ из-за перерыва: **−4,9 Гр** (или «потеря 4,9 Гр» в зависимости от знака поля). Относительная величина `(47−40)×0,7=4,9`. В самом BCR значение связано с наблюдавшимся различием времени ACC `40/47 дней`, не с индивидуальным прогнозом контроля опухоли. **PASS ±0,01 Гр**, отсутствие безусловной клинической рекомендации.

### Ф-06. BCR 2025, пример 10.5, стр. 109–110 (PDF 124–125): пропущена средняя из 5×5 Гр

**Калькуляторы → Коррекция курса / ошибки дозы**. Ввести:
- `План: число фракций=5`, `План: доза / фракцию=5 Гр`;
- `Уже доставлено фракций=2`; `Фактическая доза / фракцию=5 Гр`;
- `Оставшихся фракций=2` (среда пропущена; чт/пт остаются);
- `α/β=10 Гр` — **условно принято в книжной задаче** для контроля опухоли.

Получить `Новая доза / фракцию ≈6,73 Гр` (публикуется как **6,7 Гр**, математическое решение **6,726 Гр**). Требуемый EQD₂ для оставшихся `3×5` = **18,75 Гр**; ***не сравнивать округлённые 2×6,7 с 18,75 как точное равенство***. **PASS ±0,03 Гр для 6,726 Гр**. Отметить предупреждение о росте дозы на фракцию и необходимости проверки ОАР.

**Вторая половина того же примера, риск кишечника.** Вручную отдельно оценить `α/β=4`:
- Исходные `5×5`: `EQD₂=37,50 Гр`.
- При `2×5 + 2×6,7`: вклад первой пары `15,00 Гр`, второй `23,897 Гр`, **в сумме 38,90 Гр**.
- При `α/β=1,7` для подкожного фиброза: по книге примерно **45 → 48,5 Гр**.
- **PASS**, если рецензент фиксирует повышение EQD₂ нормальных тканей несмотря на сохранение модельной опухолевой EQD₂. **Без подтверждения геометрии и реального DVH нельзя утверждать, что заданная OAR получает полную дозу мишени.** Здесь это учебный пример.

### Ф-07. BCR 2025, пример 10.6, стр. 110 (PDF 125): ошибка 2×4 вместо 2×2 Гр

**Калькуляторы → Коррекция курса / ошибки дозы**:
- `План: число фракций=35`;
- `План: доза / фракцию=2`;
- `Уже доставлено фракций=2`;
- `Фактическая доза / фракцию=4`;
- `Оставшихся фракций=36`;
- `α/β=10` **ручное учебное значение для решения с фиксированным n=36**.

Ожидается `Новая доза/фракцию≈1,72 Гр`; книга приводит математическое `d=1,7419 Гр` при непрерывно выбираемом числе фракций `35,6` и практическое округление `36×1,72 Гр`. **Это два разных условия задачи:** HFC фиксирует целое `n=36` и подбирает `d` при явно выбранном α/β, что даёт примерно `1,72475 Гр`; не требовать ровно 1,7419 в этом поле. **PASS ±0,01 Гр от 1,72** и обязательная проверка общего времени курса и ОАР.

### Ф-08. Обязательные отрицательные тесты

1. В **Быстрый BED / EQD₂** поставить `n=0`: ожидается сообщение о неверном числе фракций, **а не численный ответ**.
2. Поставить `α/β=0` в пользовательском режиме: ожидается отказ от расчёта, не `Infinity` или `NaN`.
3. В **Перерывы в лечении** открыть endpoint медуллобластома: две ставки Hinata, относящиеся к **BED/tBEDmax**, **не должны** предлагаться для нового автоматического выбора `Dprolif EQD₂/day`.
4. Импортировать старый `audit JSON` с ID `dprolif-hn-various-bcr2025` или Hinata (см. автоматические fixtures в [browser test](../e2e/hfc.audit-replay-clinical.pw.ts)): **Методология → Проверка сохранённого расчёта → выбрать JSON**. SHA-256 проверен, запись и архивные числа открываются, но новый расчёт **заблокирован и не выдаёт автоматическую замену модели**. Повреждённый SHA отвергается ещё раньше.
5. **НЕ** использовать экранный EBRT Quick EQD для «проверки» BCR 2025 пример 10.3 с непрерывной брахитерапией **5 Гр за 2,5 ч**: источник требует интегрального Lea–Catcheside `g`, а не предположения об мгновенной фракции. Точная публикационная эталонная задача `T½=5ч EQD₂=7,4` и `T½=1,5ч EQD₂=6,5` остаётся **NOT APPLICABLE** к текущему EBRT workflow. Это **ограничение области применимости, а не FAIL**.
6. При `d>10 Гр` смотреть предупреждение HFC об экстраполяции простой LQ; не использовать высокие SBRT дозы для заведомо невалидного теста эквивалентности без endpoint-specific независимого эталона.

## B. Врач-радиотерапевт: клинические контрольные вопросы и критерии

Врач рассматривает те же **Ф-01, Ф-02, Ф-05, Ф-06, Ф-07, Ф-08**, но результаты оценивает не как подбор схемы для пациента, а как **проверку корректности интерпретации**:

| ID | Ситуация | Что врач должен проверить | Неприемлемый вывод платформы / рецензента |
|---|---|---|---|
| В-01 | 1×8, 4×5 для спинного мозга | EQD₂ 20/35 — LQ-модель при α/β=2, **не** ограничение Dmax на спинной мозг пациента | «35 Гр EQD₂ автоматически безопасно» |
| В-02 | RAPID 38,5/10 BID | Выбран косметический endpoint, учитывается неполная репарация; различие 51,7 vs 62,4 vs 64,9 сопровождается методологическим контекстом | «При BID всегда достаточно межфракционного интервала 6 ч для поздней токсичности» |
| В-03 | IAEA ACC 40/47 | 0,7 EQD₂/сут — ретроспективная приближённая оценка, ограниченная опухолевой популяцией и окном OTT | «Любой рак теряет 0,7 Гр в день на любом сроке» |
| В-04 | Пропущена фракция 5×5 | У опухоли можно восстановить LQ EQD₂, но для кишечника модельные 37,5→38,9 Гр **выше**, а DVH неизвестен | «6,7 Гр на оставшиеся два сеанса клинически эквивалентно и безопасно» |
| В-05 | Избыточная доза 2×4 | Доступность трёх дополнительных дней/фракций и ОАР требуют отдельного планирования; результат 36×1,72 — математический сценарий | «Исправление завершено без клинического перепланирования» |
| В-06 | Medulloblastoma / Hinata | Историческая модель BED/tBEDmax недоступна в стандартном EQD₂ time-loss подборе | «Можно взять 0,55 из BED/day как EQD₂/day» |
| В-07 | Нет исходных DVH и объёмов | Нельзя утверждать NTCP или нормотканевую безопасность из одной суммарной дозы мишени | «Сравнены риски ОАР количественно по одной дозе на мишень» |
| В-08 | Публикационные α/β и CI | Проверить endpoint, исходные популяции, гипофракционирование, uncertainty; не переносить общие 3/10 на специфические ткани | «Одна α/β подходит одновременно для разных осложнений» |

**Врач ставит PASS только если:**
- умеет воспроизвести и объяснить источник каждого числа/допущения;
- предупреждения HFC не скрывают повышение риска при коррекции режимов;
- нигде не выдано «клинически безопасно» только из совпадения BED/EQD₂;
- источник `tBEDmax`, брахитерапевтическая `g`-модель или неприменимая OAR константа не подставлены молча.
