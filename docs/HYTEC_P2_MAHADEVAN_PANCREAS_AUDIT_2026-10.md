# P2.11 — Mahadevan et al. 2021: pancreas SBRT 1-year LC, unresected vs R0

**Дата:** 2026-10-08. **Статус:** аудит первичной опубликованной модели и трёх уже реализованных HFC точек; не independent refit, не validation новых клинических TCP.

**Source:** `HyTEC_17_Mahadevan_2021_Pancreas_SBRT.pdf` (11 PDF pages), DOI **10.1016/j.ijrobp.2020.11.017**. Критические **PDF p6 Figure 1**, **p7 Eq/model, Table 2** визуально / текстом сверены; p2 Abstract, p3 Endpoints, p8 Recommended Objectives, p9 Table 3 также прочитаны. Дополнение `HyTEC_17_Mahadevan_2021_Pancreas_SBRT_supplement.doc` рассмотрено для перекрывающихся категорий (Appendix E1), неоднородных Kaplan–Meier timeline (Figure A2).

## 1. Исходные клинические различия

Авторы объединили **8 наблюдений из исследований с ≥80% случаев без резекции** для модели локального контроля через 1 год после SBRT. Категории BRPC/LAPC, неоадъювантная терапия, R0, «resected vs unresected» и первичные зоны опухоли в исходных работах неоднородны. При анализе 3 серий R0-резекции авторы **не построили убедительной независимой дозозависимой TCP-кривой**, а использовали усреднённую оценку из отдельных наблюдений. Нельзя считать обе группы одной функцией (TCP(D)).

Разные журнальные наблюдения начинали Kaplan–Meier анализ от времени диагноза (32%), SBRT (42%) и других временных точек (26%). Это способно завышать сравнимый 1-летний LC, особенно при наличии предоперационной химиотерапии / последующего Whipple. Авторы прямо оговаривают короткий follow-up, неодинаковые методы определения progression и риски competing events.

## 2. Дозное преобразование (LQ α/β = 10 Гр)

`BED10 = D*(1 + D/(n*10))`, `D3eq = ( -3*10 + sqrt((3*10)^2 + 4*(3*10)*BED10 ) ) / 2`.

Table 2 даёт `33 Gy/5fx -> 28.2 Gy/3fx equivalent`; точное из авторской LQ формулы значение **28.2249927704 Gy**, округление до 28.2 корректно. `36 Gy/3fx -> 36.0 Gy/3fx equivalent`.

Для **unresected** Table 2 / PDF p7, авторская логистическая формула: `TCP=1/[1+(D50/D3eq)^(4*gamma50)]`, при:
- **D50 = 17.6 Gy** в 3-fraction equivalent (95% CI **8.8–21.5**);
- **gamma50 = 0.64** (95% CI **0.27–1.02**);
- fitted association **P=.002** (Fisher exact test, *как представлено авторами*, не интерпретировать как пациентскую калибровку).

| HFC record | Физическая доза | D3eq_αβ10 | Recomputed 1y LC | HFC source rounded | Difference |
|---|---|---:|---:|---:|---:|
| `pancreas-unresected-33gy5fx-77lc` | 33 Gy /5 | 28.224993 Gy | **77.01416%** | ≈77% | +0.0142 п.п. |
| `pancreas-unresected-36gy3fx-86lc` | 36 Gy /3 | 36 Gy | **86.19983%** | ≈86% | +0.1998 п.п. |

**Две HFC точки воспроизводятся** с погрешностью округления ≤0.20 п.п. Модель не работает автоматически на Р0-группе и не учитывает гистологическую/геометрическую дозовую неоднородность, TVI SIB, системную терапию или риск осложнений ЖКТ.

## 3. R0 — отдельный опубликованный исход, не fitted dose-response

Для `pancreas-r0-33gy5fx-over90lc` HFC хранит **probability=0.90 и relation `>`** для 33 Gy/5fx / 28.2Gy3eq. Сверка выявляет **внутри одного источника две формы отображения результата**:

- **PDF p2 Abstract и p8 clinical summary:** локальный контроль в группе R0 **>90%** при D3eq примерно >28 Gy;
- **PDF p7 Table 2:** та же категория 33Gy/5fx указана как **90%** (округлённая оценка), при этом в тексте отдельно приводится weighted mean ~96% для трёх небольших R0 series.

Это НЕ независимая «R0 logistic fit» с определёнными D50 и gamma50. Подстановка R0 в unresected curve даёт ≈77%, а не «усреднённые 90/96%» по отдельным R0 сериям. **Нельзя выводить новый коэффициент R0, автоматически повышать дозу или заменять исходный HFC процент арифметическим результатом другой когорты.**

Поскольку формулировка HFC `>90%` буквально соответствует Abstract/clinical summary, **число и знак сохранены**, но научная трассировка теперь явно фиксирует различие с Table 2 `90%`. Это **source-reporting/rounding ambiguity**: до независимого заключения автора/рецензента не представлять `>90%` как достоверно доказанный строгий нижний bound при конкретном режиме.
