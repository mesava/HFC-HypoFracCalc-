# HFC — закрытие замечаний независимого аудита P4-TB-2.0 по интерфейсу

**Дата:** 14 октября 2026 г.  
**Источник замечаний:** `HFC_P4_Independent_Validation_2026-10-14(2).pdf`, 3 стр., независимо подготовленный аудит **исходного коммита `b2217ba` от 12.10.2026**. Поставленные в нём `P1` замечания касались отсутствия сквозных браузерных маршрутов F-03/F-04/F-05/F-06/F-07. В версии HFC от 14.10 уже существовали исправления календаря, печати и частичной локализации (PR #63/#64), поэтому повторно считать их отсутствующими некорректно.

## Ограничение утверждений

- Статусы ниже обозначают **автоматическое функциональное тестирование UI на конкретном коммите**, с настоящими событиями ввода пользователя в браузере Chromium; это **не независимая клиническая приёмка** и не подписание внешним медицинским физиком или врачом-радиотерапевтом.
- Исходные published benchmarks: пользовательские `Basic Clinical Radiobiology 2025`, гл.10, примеры 10.2, 10.4, 10.5 и 10.6, а также русские `Основы клинической радиобиологии` 2014, гл.9, пример 2. Книжные значения сопоставляются с построенной рабочей моделью; исходные учебники остаются первичной для данного теста системой задания, а не `HFC`.
- **Нет изменений** `src/core/`, `src/workflows/`, опубликованных α/β, Dprolif, T½, Tk, математических формул, ограничений ОАР, источников и `releaseStatus:draft`.
- Каждое сквозное испытание прикрепляет снимок отображённого результата через `test.info().attach` к отчёту Playwright. Материалы доступны в артефакте `playwright-report` соответствующего CI; для корректного цитирования необходимо указать точный SHA тестируемой ветки.

## Что закрывается, а что нет

- **Закрывается на уровне разработки/CI:** отсутствовавшие сквозные маршруты Ф-03–Ф-07 и найденные прямые выводы англоязычных предупреждений коррекции курса. Подтверждение — итоговый **зелёный** GitHub Actions run; если любой run красный, данный пункт **не считать завершённым**.
- **Не закрывается без внешних подписей:** полный независимый ручной прогон опубликованного URL с фиксацией SHA, выбор верной популяции и α/β, оценка нормотканевых ограничений (DVH и Dmax), клиническая допустимость BID и эскалации дозы. Согласованность BED/EQD₂ не даёт разрешения на лечение.
- Научная модель `Hinata tBEDmax` осталась отдельным архивным исследовательским вопросом; расчётные блокировки источников по BED/EQD₂ не сняты.

## Как получить машинные доказательства

Перейти в [PR #65](https://github.com/mesava/HFC-HypoFracCalc-/pull/65) → **Checks** → успешный запуск **CI** → **Artifacts** → `playwright-report`. Там открыть семь новых сценариев `e2e/hfc.p4-textbook-full-ui.pw.ts` и их вложенные скриншоты. Исходный код и порядок ввода представлены в тесте и могут воспроизводиться на публичном HFC только после публикации этих изменений в `main`.
